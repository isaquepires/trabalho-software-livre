## Desenvolvimento
O `tarefas.sh` é um script em bash pequeno que opera diretamente no terminal, portanto, seguimos os exemplos do proprio pdf para guiar o todo o processo de desenvolvimento. E os testes foram realizados de diversas formas diferentes, com o devido tratamento de erros para entradas sem conformidade com o padrão requerido.

Ao longo de todo o código fonte foram feitos comentários para constar de que maneira foi resolvido cada desafio proposto. Além disso, prezamos pela legibilidade e encapsulamento das funções, trazendo sempre simplicidade e eficiência na execução.
