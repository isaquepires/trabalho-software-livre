## Desenvolvimento
O `tarefas.sh` é um script em bash pequeno que opera diretamente no terminal, portanto, seguimos os exemplos do proprio pdf para guiar o todo o processo de desenvolvimento. Além disso, os testes foram realizados de diversas formas diferentes, com o devido tratamento de erros para entradas sem conformidade com o padrão requerido. Em especial, consultar os materiais de laboratório disponibilizados no site do Prof. Gabriel V. C. Candido foi muito importante para nosso auxílio.

## Código
Ao longo de todo o código fonte foram feitos comentários para constar de que maneira foi resolvido cada desafio proposto. Além disso, prezamos pela legibilidade e encapsulamento das funções, trazendo sempre simplicidade e eficiência na execução. Destacamos funções auxiliares que vão além do escopo das opções, como a ordenação ao listar as tarefas feitas, o próprio código da listagem e a independência da posição de argumentos, tudo isso mostrou que um script em Bash pode ser muito poderoso.
